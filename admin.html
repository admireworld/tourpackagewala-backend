Taxes, fees & margin

These percentages are added automatically on top of hotel + sightseeing + pickup/drop + visa when the final total is calculated. Margin is applied first (your own markup on the base cost), then tax is applied on top of that. The customer never sees either as a separate line — both are always baked into the one combined total shown to them.

Default is 0% — existing quotes/packages keep showing the exact same price until you set this above 0.

Taxi Fares

Add a taxi route

Every city and price on the website's Taxi Service — Fare Calculator page comes from here. Changes show on the site within about 30 seconds. Leave a price empty (or 0) to show "On request". With "both ways" ON, the same fare also works for To → From.

Bulk add / update (paste many routes at once)

One route per line: From, To, KM, Sedan, Ertiga, Innova, Tempo Traveller. A From + To pair that already exists is updated, new ones are added. You can paste straight from Excel / Google Sheets too.

Settings

Contact details

Shown in the site footer and used for every "Chat on WhatsApp" button. Changes apply the next time a visitor loads the page.

AI Content Provider

Controls what writes the daily blog post and the weekly auto-added package. Switching provider or updating a key here takes effect on the very next post — no code change or redeploy needed. If the selected provider ever fails (bad/expired key, quota, etc.), it automatically falls back to the free option so content generation is never blocked.
